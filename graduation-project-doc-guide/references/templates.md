# Templates

Contents: Template 1 – Title page · Template 2 – Table of contents

## Template 1: Title page

Use this vertical order, centered, in the document's language. Placeholders are in brackets. Fill them from what the user supplies; leave a clearly marked placeholder if something is unknown.

```
[College logo – optional]

كلية تقنية الحاسوب – طرابلس
قسم تقنيات البرمجة
(College of Computer Technology – Tripoli
Programming Technologies Department)

[PROJECT TITLE – large, clear, bold font, in a shaded box in the original]

مشروع تخرج مقدم ضمن متطلبات الحصول على درجة البكالوريوس / الدبلوم العالي في مجال تقنيات البرمجة
(Graduation project submitted within the requirements for the Bachelor's / Higher Diploma degree in Programming Technologies)

إعداد: [اسم الطالب] – [رقم القيد]
(Prepared by: [Student name] – [Enrollment number])

إشراف: [اسم المشرف]
(Supervised by: [Supervisor name])

[الفصل الدراسي / السنة – e.g., ربيع 2014–2015]
(Semester / year – e.g., Spring 2014–2015)
```

Notes:
- Project name is in the same language as the rest of the document; for bachelor projects the enrollment number may follow the student's name.
- For multiple students, list each on its own line.
- Keep standard margins; no decorative borders or colored covers.

The list of tables and the list of figures use the same two-column pattern (caption … page), e.g.:

```
Table 1 – ASCII codes for characters ........ 1
Table 2 – Data types and their ranges ....... 3
```
