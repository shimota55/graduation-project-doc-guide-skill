# Writing the list of references

## General rules

- Title the list "List of References" (قائمة المراجع).
- Write each reference as a numbered entry (number followed by a dot or dash). Order entries either alphabetically by author surname or by order of citation in the project; **citation order is preferred**.
- Each reference's details are written in one continuous line. If a single reference needs more than one line, use single spacing inside it and leave one blank line between references.
- In the text, cite a reference by its number inside square brackets, e.g. [3].
- English-language references are written in English.
- If the project has both Arabic and English references, split the list into two sections: Arabic references and English references.

## General entry layout for a book

Last name of author, first name; title of the book; edition number; ISBN; publisher; year of publication; place of publication; pages used.

- If there is only one edition of the reference, do not write the edition number.
- The ISBN may be omitted if it does not exist.

## Entry layout by source type

**Books**: author name, publisher/company name, book title, publisher showing city and country, year of publication.

**Encyclopedias**: full name of the encyclopedia, volume number consulted, publisher (company) name, title, city and country, year of publication.

**Papers (research articles)**: author name, "title of the published paper", name of the journal in which it was published, journal volume or part number if issued in volumes, page numbers of the paper, month, year of publication.

**Other academic work (graduation projects, master's and doctoral theses)**: author name, "title of the work", name of the institution where the work was done (e.g., university), city, country, year of publication.

**Websites**: include the live link (hyperlink) of the site used with the relevant details. Example from the guide:

> Social Entrepreneurs Inc., (2003). *Overview of Approaches to Strategic Planning*. Article http://www.socialent.com. Access date 20/01/2014

Always include the access date for web sources.
