# Graduation Project Documentation Skill — مهارة توثيق مشاريع التخرج

مهارة (Skill) لـ Claude تساعد الطلبة على كتابة وتنسيق ومراجعة توثيق مشاريع التخرج وفق **دليل توثيق مشاريع التخرج** لقسم تقنيات البرمجة، كلية تقنية الحاسوب – طرابلس (الإصدار الثالث، 2014، إعداد د. عقيل محمد عقيل).

> ⚠️ هذا المشروع **غير رسمي** ولا يمثل الكلية أو القسم. المرجع المعتمد دائماً هو الدليل الأصلي، وعند أي اختلاف يؤخذ بالدليل أو بتوجيه المشرف.

## ماذا تفعل؟

- تنسيق ملف Word: هوامش، خط، أحجام العناوين، تباعد الأسطر، الهيدر والفوتر، ترقيم الصفحات والعناوين.
- بناء هيكل التوثيق الكامل: صفحة العنوان، الشكر، المستخلص، الفهارس، الفصول، المراجع، الملاحق.
- كتابة قائمة المراجع وتنسيقها (كتب، أبحاث، رسائل، مواقع).
- مراجعة مسودة وإعطاء قائمة أخطاء محددة مع طريقة الإصلاح.
- توليد ملفات Word عربية من اليمين لليسار بشكل صحيح.

## طريقة التثبيت

### في Claude (claude.ai أو التطبيق)
1. نزّل المستودع (Code ← Download ZIP) أو نزّل ملف `graduation-project-doc-guide.skill` من صفحة Releases إن وُجد.
2. اضغط ملف المجلد `graduation-project-doc-guide` إلى ZIP (يجب أن يكون `SKILL.md` داخل المجلد).
3. افتح **Customize ← Skills ← Upload skill** وارفع الملف، ثم فعّل المهارة.

### في Claude Code
انسخ المجلد `graduation-project-doc-guide` إلى `~/.claude/skills/` (لكل مشاريعك) أو إلى `.claude/skills/` داخل المشروع.

## أمثلة للاستخدام

- «اكتب لي صفحة العنوان لمشروع تخرجي حسب دليل التوثيق»
- «راجع هذا الملف وقل لي ما المخالف لدليل التوثيق»
- «جهّز لي فهرس محتويات لمشروع نظام إدارة مكتبة»
- «رتب لي قائمة المراجع التالية بصيغة الدليل»

مثال على المخرجات في `examples/sample-chapter-page.docx`.

## ملاحظات

- الخط المضبوط في هذه النسخة **Times New Roman**، بينما يحدد الدليل الأصلي **Arabic Transparent**. لإعادته للخط الأصلي عدّل الخط في `references/formatting-spec.md` و`SKILL.md`.
- نص المهارة استُخرج من ملف PDF للدليل وقد تكون فيه أخطاء استخراج، فقارن الأرقام المهمة (الهوامش، الأحجام، 80 صفحة) بالدليل الأصلي.
- الدليل الأصلي من تأليف د. عقيل محمد عقيل. هذا المستودع ملخص عملي لقواعده لمساعدة الطلبة، وليس بديلاً عنه.
